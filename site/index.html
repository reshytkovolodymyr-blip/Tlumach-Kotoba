Встановлення

Кілька хвилин — і можна створювати перший урок.

1. Завантаж програму

Натисни «Завантажити для Windows» — це один файл TlumachKotoba.exe, Python встановлювати не потрібно.

2. Встанови FFmpeg

Потрібен, щоб складати репліки в один MP3. Найпростіше — у PowerShell: winget install --id Gyan.FFmpeg -e

3. Запусти

Файл поки не має цифрового підпису, тож Windows може показати «Windows захистив ваш ПК». Натисни «Докладніше» → «Виконати в будь-якому разі».

4. Створи перший урок

Майстер підкаже промпт для AI. Встав відповідь, обери голоси — і створи MP3.

Спробуй Tlumach Kotoba

Один файл для Windows — без встановлення Python. Створи перший урок за кілька хвилин.
