# Сторонні компоненти

`TlumachKotoba.exe` містить такі сторонні програми й бібліотеки:

| Компонент | Ліцензія | Джерело |
| --- | --- | --- |
| FFmpeg (через imageio-ffmpeg) | GNU LGPL / GPL | https://ffmpeg.org/download.html |
| imageio-ffmpeg | BSD-2-Clause | https://github.com/imageio/imageio-ffmpeg |
| PySide6 (Qt for Python) | GNU LGPL v3 | https://www.qt.io/qt-for-python |
| edge-tts | GNU LGPL v3 / GPL v3 | https://github.com/rany2/edge-tts |
| pykakasi | GNU GPL v3 | https://codeberg.org/miurahr/pykakasi |
| pygame-ce | GNU LGPL v2.1 | https://github.com/pygame-community/pygame-ce |

Сам Tlumach Kotoba поширюється під GNU GPL v3 (див. `LICENSE`). Вихідний
код кожного компонента доступний за посиланням у таблиці.
