=================================================================
  TLUMACH KOTOBA
  Тренажер англійської та японської мов для україномовних
=================================================================

ГОЛОВНИЙ ПРИНЦИП:
    AI (ChatGPT тощо) створює діалог. Ви вставляєте його в програму.
    Програма перетворює текст на структурований урок і аудіо з паузами.
    OpenAI API key НЕ потрібен.

ПОТОЧНА ІТЕРАЦІЯ:
    При старті програми відкривається майстер, що формує ГОТОВИЙ
    ПРОМПТ для зовнішнього AI (мова + рівень + тема). В інтерфейсі —
    три окремі режими (перемикач): Full Dialogue, Shadowing (3 проходи
    зі зростаючою складністю) і Ключові фрази (двонапрямковий Phrase
    Trainer). За раз обирається й генерується лише ОДИН режим — файли
    не комбінуються. Recall / Reverse Recall НЕ видалені з коду
    (app/exercises.py) — протестовані й готові, просто ще не
    підключені в GUI.

    Інтерфейс побудований на PySide6 (Qt) — перехід із Tkinter/
    ttkbootstrap, бо Tkinter не вміє вбудовувати власні файли шрифтів
    і не має нативної підтримки SVG-іконок. Довгий урок з багатьма
    фразами не виштовхує кнопки за межі вікна — Qt-віджети скроляться
    самі. Панель "ПОТОЧНИЙ УРОК" з дублюючими даними прибрана — уся ця
    інформація видима одразу у прев'ю уроку внизу вікна.

    Вбудований аудіоплеєр (на pygame-ce) дозволяє прослухати щойно
    створений MP3 прямо в застосунку — без відкриття сторонньої
    програми. Історія уроків тепер зберігає ПОВНИЙ оригінальний
    текст від AI (raw_text), а не тільки розібрані дані — відкриття
    уроку з History відновлює точний вхідний текст у полі редагування.

    Мови вивчення: English, Japanese, Français, Español — усі за
    однаковою архітектурою (app/languages.py), голоси перевірені
    через реальний вивід edge-tts --list-voices.

    Навігація на 4 розділи вгорі вікна: "Новий урок" (створення й
    обробка уроку), "Мої уроки" (історія + Export/Import JSON),
    "Методологія" (наукове обґрунтування методу, UK/EN), "Про
    програму" (окреме інформаційне вікно). Мова інтерфейсу (UK/EN)
    перемикається в шапці — застосовується після перезапуску
    застосунку (свідомо, не миттєво — надійніше, менше ризику щось
    пропустити при живому оновленні кожного віджета).

       перетягнути файли через веб-інтерфейс, без командного рядка.
    2. Відкрийте вкладку "Actions" у своєму репозиторії.
    3. Якщо збірка не почалась сама (стається одразу після
       завантаження файлів) — натисніть "Build Windows EXE" зліва,
       тоді "Run workflow" праворуч.
    4. Зачекайте кілька хвилин, відкрийте завершений запуск, і

       "TlumachKotoba-windows-exe" — це готовий .exe в zip-архіві.

    Той самий застереження, що й для локальної збірки: FFmpeg у цей
    .exe НЕ включений — на машині, де .exe запускатиметься, ffmpeg
    має бути встановлений окремо і в PATH.

3. ЯК КОРИСТУВАТИСЬ
-----------------------------------------------------------------

КРОК 0 — Майстер промпту (з'являється автоматично при старті,
          можна повторно відкрити кнопкою "🎯 Новий промпт"):
    a. Оберіть мову вивчення, рівень і тему діалогу.
    b. Натисніть "Згенерувати промпт".
    c. "📋 Копіювати промпт" і вставте його у свій AI-чат (ChatGPT
       тощо), або одразу "Далі → вставити діалог", щоб перейти в
       головне вікно з попередньо заповненою мовою/рівнем/назвою.

КРОК 1-6 — Головне вікно:
    1. Вставте відповідь AI у поле "1. Діалог від AI" (Ctrl+V,
       Shift+Insert, права кнопка миші, або кнопка "Вставити з
       буфера"). Стандартні Ctrl+C/V/X/A працюють у всіх текстових
       полях і діалогових вікнах програми.
    2. Натисніть "Розібрати НОВИЙ діалог" — це створює CURRENT
       SESSION.
    3. У блоці "2. Голоси спікерів" оберіть чоловічий/жіночий голос
       для КОЖНОГО імені з діалогу. Це обов'язково вручну.
    4. Оберіть темп і паузу між репліками.
    5. Натисніть "🔊 Створити MP3". Файл з'явиться в output/ і
       одразу завантажиться в блок "4. Плеєр" (без автоматичного
       відтворення) — натисніть ▶, щоб прослухати прямо в
       застосунку, без сторонньої програми.
    6. Подвійний клік по запису в "Історія уроків" відновлює НЕ
       лише розібрані дані, а весь оригінальний текст від AI —
       поле "Діалог від AI", назву, мову й рівень буде заповнено
       так само, як було при створенні уроку.
    7. Урок можна видалити з історії правою кнопкою миші по запису
       ("Видалити"), або одразу всю історію кнопкою "🗑 Очистити
       всю історію" над списком.

Для японської мови в перегляді (внизу вікна) під кожною реплікою і
фразою показується romaji в квадратних дужках — це лише допоміжна
вимова для читання, озвучується завжди оригінальний kanji/kana текст.

4. ГОЛОСИ TTS (edge-tts)
-----------------------------------------------------------------

English:   Guy (чоловічий) / Jenny (жіночий)
Japanese:  Keita (чоловічий) / Nanami (жіночий)
Ukrainian (переклади/пояснення): Остап (чоловічий) / Поліна (жіночий)

Користувач обирає ЛИШЕ стать для кожного спікера (чоловічий/жіночий)
у блоці "2. Голоси спікерів". Конкретну модель голосу в межах цієї
статі підбирає програма (app/languages.py: pick_voice()/
pick_native_voice()) — механізм зроблено саме для майбутньої
різноманітності, але ЗАРАЗ пул навмисно звужений до РІВНО ОДНОГО
голосу на стать.

Причина: голоси на кшталт en-US-DavisNeural чи ja-JP-DaichiNeural
дійсно існують в офіційному каталозі Microsoft Azure — але edge-tts,
яким користується застосунок, це НЕОФІЦІЙНА бібліотека, що звертається
до вужчого внутрішнього сервісу "Читати вголос" у Microsoft Edge, а не
до платного Azure API. Належність голосу до Azure НЕ гарантує його
доступність через edge-tts. Розширений пул призводив до помилки
"Не вдалося підключитися до TTS" для голосів поза цим вузьким набором.

Якщо колись знадобиться розширити пул — єдиний надійний спосіб це
зробити: на машині з Internet виконати

    edge-tts --list-voices | findstr "en-US ja-JP"

і додавати в app/languages.py лише голоси з РЕАЛЬНОГО виводу цієї
команди, ніколи — за офіційною документацією Azure чи сторонніми
списками.

Додати нову мову вивчення в майбутньому — один новий запис у
app/languages.py, без змін у tts.py/exercises.py/gui.py.


-----------------------------------------------------------------
4a. КЛЮЧОВІ ФРАЗИ — ВИКЛЮЧНО ВІД AI
-----------------------------------------------------------------

Ключові фрази для режиму "Ключові фрази" беруться ТІЛЬКИ зі списку
"фраза - переклад", який AI додав під діалогом (з номером чи без —
AI часто забуває нумерувати, парсер розпізнає обидва варіанти). У
програмі немає і не буде власного автовиділення фраз "здогадкою" з
тексту — раніше такий fallback існував для англійської (пошук
патернів типу "Could you", "I'd like to"), він свідомо прибраний як
ненадійний і однобічний.

Тому промпт із майстра (app/prompt_builder.py) явно й наполегливо
вимагає від AI список 5-8 фраз у точному форматі:

    1. фраза - переклад українською | приклад: повне речення з фразою

Якщо AI список не додав — Phrase Trainer для цього уроку буде
недоступний (чесне повідомлення, а не вигадані фрази).

5. ПОВІДОМЛЕННЯ ПРО ПОМИЛКИ
-----------------------------------------------------------------

"FFmpeg не знайдено. Встановіть FFmpeg і повторіть."
"Не вдалося підключитися до TTS. Перевірте Internet."
"Не знайдено реплік. Використовуйте формат Speaker: text."
"Спочатку створіть або завантажте урок."
"Оберіть голос для кожного спікера перед створенням аудіо: ..."
"У цьому уроці немає ключових фраз для цього режиму."

Якщо файл із таким іменем (назва_рівень_режим.mp3) уже існує в
output/, програма ЗАПИТАЄ, перш ніж щось робити: перезаписати
існуючий файл, зберегти як новий (з суфіксом _2, _3...), чи
скасувати створення. Якщо ви оберете "перезаписати" саме того файлу,
що зараз завантажений у вбудований плеєр — застосунок сам звільнить
його (player.unload()) перед записом, щоб уникнути помилки Windows
"Permission denied" (файл, завантажений у pygame/SDL_mixer, інакше
лишається "зайнятим" навіть після натискання Stop).

Окремо про встановлення: якщо INSTALL.bat падає на кроці pygame-ce
з помилкою на кшталт "ModuleNotFoundError: No module named
'setuptools._distutils.msvccompiler'" — це НЕ проблема з Internet
(текст помилки, на жаль, вводить в оману). Причина: у вас дуже нова
версія Python (3.13/3.14), для якої в PyPI ще немає готової збірки,
і pip намагається зібрати пакет із вихідного коду — а стара система
збірки шукає модуль distutils, якого в новому Python вже нема. У
requirements.txt навмисно вказано "pygame-ce" (а не класичний
pygame) саме тому, що він має готові збірки для нових версій Python
— переконайтесь, що встановлюється саме він (`pip show pygame-ce`).
Якщо проблема лишається — встановіть Python 3.11 чи 3.12 окремо і
запустіть INSTALL.bat/START_APP.bat через нього (`py -3.12 -m pip
install -r requirements.txt`, `py -3.12 tlumach_kotoba.py`).

Про PySide6: це велика бібліотека (сотні мегабайт), встановлення
може зайняти кілька хвилин — це нормально, не зависання. Якщо
INSTALL.bat падає саме на кроці PySide6 без зрозумілої причини —
спробуйте `pip install --upgrade pip` перед повторною спробою
(стара версія pip іноді не бачить готові збірки для нових версій
Python).


-----------------------------------------------------------------
6. АРХІТЕКТУРНІ РІШЕННЯ
-----------------------------------------------------------------

- "practice" (пари питання-відповідь для Recall) НІКОЛИ не
  зберігається — завжди обчислюється на льоту з dialogue
  (LessonSession.practice_pairs). Актуально навіть із вимкненим
  у GUI режимом Recall — сама логіка лишається готовою.
- Голос спікера завжди обирається вручну (speaker_voices у сесії),
  зберігається разом з уроком і відновлюється з History.
- Тимчасові аудіофрагменти видаляються навіть при помилці
  (AudioAssembler.build використовує finally).
- Майстер промпту (wizard.py) нічого не знає про SessionManager чи
  TTS — лише формує текст і передає обрані мову/рівень/тему в
  головне вікно через callback.

7. ОБОВ'ЯЗКОВИЙ ТЕСТ CURRENT SESSION
-----------------------------------------------------------------

Запустіть:  py tests/test_current_session.py

Він відтворює сценарій: Airport B2 (English) → Hotel B1 (English) →
Shadowing (тільки Hotel) → History→Airport → Recall (тільки Airport) →
Job Interview B2 → усі режими тільки з Job Interview. Також перевіряє,
що без призначення голосу спікеру MissingVoiceError блокує генерацію.
Тест звертається до exercises.py напряму, тому продовжує перевіряти
всі 5 режимів навіть попри те, що GUI наразі показує лише Full Dialogue.

Для перевірки романізації:  py tests/test_japanese_reading.py
(автоматично пропускається, якщо pykakasi не встановлено).

Для перевірки Shadowing (3 проходи) і Phrase Trainer (приклади,
двонапрямковість):  py tests/test_shadowing_and_phrases.py
